# Seguridad

- El archivo `.env` contiene secretos y no debe publicarse.
- Revoca inmediatamente cualquier clave expuesta.
- Usa claves de solo lectura para datos cuando el proveedor lo permita.
- La futura ejecución de órdenes debe usar una cuenta paper separada, límites por operación, pérdida diaria máxima y botón de apagado.
- No ejecutes cambios generados por IA sin revisar las diferencias y las pruebas.
